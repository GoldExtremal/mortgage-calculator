# Mortgage Calculator

Простой фронтенд-проект для расчета ипотеки с использованием HTML, CSS и JavaScript.

## Цель проекта
- Показать навыки работы с Git, JS и фронтенд-разметкой.
- Создать наглядный калькулятор с графиками и таблицей выплат.

## Функционал
- Ввод данных:
  - Стоимость недвижимости
  - Первоначальный взнос
  - Срок кредита
  - Процентная ставка
- Расчёт:
  - Ежемесячный платёж
  - Сумма процентов
  - Общая стоимость кредита
  - Переплата в процентах
- Визуализация:
  - Круговая диаграмма (долг / проценты)
  - График изменения долей платежа по месяцам
- Таблица платежей с детализацией по месяцам и итогами

## Технологии
- HTML
- CSS
- JavaScript (ES6+)
- Chart.js для графиков
